# Changelog

All notable changes to this project will be documented here.

## 0.1.0 — Initial prototype (2026-11-03)

- GTFS ZIP/directory parser, weekly service calendar and exception handling.
- Same-stop, multiple-vehicle scheduled routing with configurable transfer limits.
- Return-journey status assessment and batch destination audits.
- Text, JSON, CSV and standalone HTML output.
- Fictional UK transport feed, regression tests, CI and clear limitation disclosures.
